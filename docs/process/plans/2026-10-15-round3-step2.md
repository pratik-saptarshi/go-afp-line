`afptoline/reduce.go` uses flat counters for group pairing. Replace
with a stack so malformed nesting is rejected:
- `BDT BNG BPG ENG EPG EDT`, `BAG BPT EAG EPT`, and
  `BPT PTX BAG EPT EAG` must all fail loudly (typed DecodeError),
  where today they are silently accepted.
- TDD: write the three rejection tests first (RED), then implement.
- Existing valid sequences (all fixtures, existing tests) must still
  pass — the stack must accept everything the counters accepted
