# Specification sources

The architecture references below are the primary sources for this
repository's AFP subset contract (`docs/subset-contract.md`). They are
**not** redistributed here — obtain them from their publishers:

- **MO:DCA Reference**, AFP Consortium, publication **AFPC-0004**
  (tenth edition). The Mixed Object Document Content Architecture
  specification: structured-field framing, object/processing semantics.
- **PTOCA Reference**, IBM, publication **SC31-6803**.
  Presentation Text Object Content Architecture: control sequences
  (including RPS semantics), descriptor fields.
- **MOCA** (Mixed Object Content Architecture) reference material,
  via the AFP Consortium.

IBM hosts AFP-related publications for viewing at
<https://www.ibm.com/docs/en/i/7.1.0?topic=afp-related-information>.
The AFP Consortium publishes its references for download; consult the
consortium for current editions and terms.

Derived notes in this directory (`contract-research.md`,
`subset-contract.md`) are the project's own work. Verbatim extracts of
the above publications were removed from this repository on 2026-10-14
because no redistribution grant was found.
