# Security Policy

## Supported Versions

Only the latest revision of `main` receives security fixes.

| Version | Supported          |
| ------- | ------------------ |
| main (latest) | :white_check_mark: |
| older revisions | :x:                |

## Reporting a Vulnerability

Please report vulnerabilities via GitHub's private vulnerability reporting:
the repository's **Security** tab → **Report a vulnerability**
(https://github.com/pratik-saptarshi/go-afp-line/security/advisories/new).

Do **not** open a public issue for a suspected vulnerability.

Please include:

- the affected revision (commit SHA) and Go version,
- steps to reproduce, including a minimal input if applicable,
- what you expected vs. what happened.

We aim to acknowledge reports within 5 business days. If the report is
confirmed, we will coordinate a fix and credit the reporter in the
advisory unless they prefer to stay anonymous.
